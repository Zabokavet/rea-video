# Posting Kit: 20 "Rules" Videos

Each entry has a **cover** (in `prompts/covers/`), a **title** and a **description**. Copy the description as-is, hashtags included.

- **TikTok:** the title goes in the description's first line (TikTok has no separate title field). Pick the cover with "Select cover", then "Upload".
- **YouTube Shorts:** paste the title into the Title field and the description into the Description field.
- **Instagram Reels:** paste the title and description together as the caption. Use "Edit cover", then "Add from camera roll". Covers keep the text centered, so the 3:4 grid crop still shows the full title.
